# WIDER FACE 人脸检测实验报告

## 1. 实验目标

使用 MMDetection 3.3.0 在 WIDER FACE 训练集上微调 RetinaNet R50-FPN，并在验证集上评估人脸检测性能。

## 2. 实验环境

| 项目 | 配置 |
|---|---|
| 操作系统 | Windows 64-bit |
| GPU | NVIDIA GeForce RTX 3080 |
| Python | 3.11.4 |
| PyTorch / CUDA | 2.1.0+cu118 / 11.8 |
| MMDetection / MMCV | 3.3.0 / 2.1.0 |
| 配置训练轮数 | 12 epochs |
| 实际完整训练 | 1 epoch |
| Batch size | 2 |
| 初始学习率 | 0.0025 |

原始配置沿用 MMDetection RetinaNet 1x 的 12 epochs 调度。实际运行后发现，在当前计算资源和时间预算下完成 12 epochs 不合适，因此保留第 1 轮检查点并用于后续评估。

## 3. 数据集

WIDER FACE 共包含 32,203 张图像和 393,703 个标注人脸，覆盖尺度、姿态和遮挡变化。本实验使用官方训练集训练、验证集评估；标注先转换为 COCO JSON。

转换后的实际统计：

| 划分 | 图像数 | 人脸框数 |
|---|---:|---:|
| Train | 12,880 | 159,393 |
| Validation | 3,226 | 39,697 |

## 4. 模型与训练设置

- 模型：RetinaNet R50-FPN
- 初始化：COCO 预训练权重
- 输入与数据增强：继承 MMDetection 官方 RetinaNet 1x 配置
- 优化器：SGD
- 评估条件：IoU = 0.5

## 5. 实验结果

| 指标 | 结果 |
|---|---:|
| bbox mAP@0.5 | 0.536 |
| 小脸 AP | 0.444 |
| 中脸 AP | 0.921 |
| 大脸 AP | 0.964 |
| AR@100 | 本次评估未单独输出 |
| AR@300 | 本次评估未单独输出 |
| AR@1000 | 本次评估未单独输出 |

评估使用 IoU = 0.5，`bbox mAP@0.5` 概括了不同置信度阈值下的 Precision–Recall 表现。本次日志没有单独输出某个置信度阈值下的 Precision，也没有输出 AR@100/300/1000，因此报告不对这些数值进行推测。最终配置已显式加入三组 AR 输出项，后续重新评估时可直接补充。

训练曲线已保存在 Notebook 中。第 1 轮内总损失从约 1.8 下降到约 0.4，表明训练过程正常且模型已学习到人脸目标特征。

## 6. 检测结果展示

Notebook 展示了 6 张 WIDER FACE 游行和乐队场景的检测结果。模型能够稳定检出近距离和中等尺度人脸，对密集合照中的多张小脸也能给出检测框。远距离、像素较少或被他人局部遮挡的人脸更容易出现漏检，且小脸框的定位精度低于中脸和大脸。

## 7. 分析与结论

本实验完成了 WIDER FACE 到 COCO 格式的标注转换、RetinaNet R50-FPN 训练、验证集评估和检测结果可视化。第 1 轮检查点的 bbox mAP@0.5 为 0.536，中脸和大脸表现较好，小脸 AP 为 0.444，仍是主要瓶颈。主要漏检来源包括远距离小脸、密集人群中的相互遮挡、大姿态和复杂背景。原始 12 epochs 配置在当前资源下耗时过长，因此本次结果定位为单轮基线，不代表充分收敛后的最佳性能。
