# LFW 与 CelebA 数据集分析报告

## 1. 分析目标

本报告基于本地数据目录对 LFW 与 CelebA 两个人脸数据集进行探索性分析。分析内容包括数据集规模、身份分布、属性分布、数据划分、标注完整性和样本特征。样本图片由 OpenCV 读取并从 BGR 转换为 RGB，再使用 Matplotlib 进行可视化。


## 2. 数据集总体对比

| 项目 | LFW | CelebA |
| --- | ---: | ---: |
| 图片数量 | 13,233 | 202,599 |
| 身份数量 | 5,749 | 10,177 |
| 图片格式 | JPEG、RGB | JPEG、RGB |
| 图片尺寸 | 全部为 250 × 250 | 对齐图像为 178 × 218 |
| 本地磁盘占用 | 约 139 MB | 约 1.7 GB |
| 主要标注 | 身份、同人/异人图片对 | 身份、40 个属性、边界框、5 个关键点、数据划分 |
| 主要用途 | 人脸验证 | 属性识别、人脸识别、关键点定位 |

## 3. LFW 数据分析

### 3.1 数据结构

本地使用的是经过人脸对齐的 `lfw-deepfunneled` 版本。每个身份对应一个文件夹，文件夹中的 JPEG 图片均属于该身份，例如：

```text
data/lfw/lfw-deepfunneled/
├── George_W_Bush/
├── Colin_Powell/
└── Tony_Blair/
```

对全部文件进行扫描后，共发现 5,749 个身份文件夹和 13,233 张图片。全部图片尺寸均为 250 × 250。

## 4. CelebA 数据分析

### 4.1 数据规模与完整性

本地 `img_align_celeba` 目录包含 202,599 张对齐后的人脸图片。抽样检查的图片尺寸均为 178 × 218。

各标注文件的图片编号均与本地图片文件名完整对应：

| 标注文件 | 数据行数 | 标注内容 |
| --- | ---: | --- |
| `identity_CelebA.txt` | 202,599 | 身份编号 |
| `list_attr_celeba.csv` | 202,599 | 40 个二值属性 |
| `list_eval_partition.csv` | 202,599 | 训练、验证和测试划分 |
| `list_landmarks_align_celeba.csv` | 202,599 | 5 个关键点的 10 个坐标 |
| `list_bbox_celeba.csv` | 202,599 | 人脸边界框 |

完整性检查未发现图片编号缺失或多余的情况。

### 4.2 身份分布

| 统计量 | 每个身份的图片数 |
| --- | ---: |
| 身份数量 | 10,177 |
| 平均值 | 19.91 |
| 标准差 | 8.93 |
| 最小值 | 1 |
| 25% 分位数 | 13 |
| 中位数 | 21 |
| 75% 分位数 | 29 |
| 最大值 | 35 |

CelebA 只有 44 个身份仅包含 1 张图片，占全部身份的 0.43%。与 LFW 相比，CelebA 每个身份通常拥有更多图片，更适合训练基于身份分类或特征嵌入的人脸识别模型。

### 4.3 训练、验证和测试划分

| 数据划分 | 图片数 | 图片占比 | 身份数 |
| --- | ---: | ---: | ---: |
| 训练集 | 162,770 | 80.34% | 8,192 |
| 验证集 | 19,867 | 9.81% | 985 |
| 测试集 | 19,962 | 9.85% | 1,000 |
| 总计 | 202,599 | 100.00% | 10,177 |

三个划分之间的身份交集均为 0。这说明同一个身份不会同时出现在训练集、验证集或测试集中，可避免人脸识别实验中的身份泄漏。

### 4.4 属性分布

CelebA 为每张图片提供 40 个二值属性，其中 `1` 表示具有该属性，`-1` 表示不具有该属性。正样本比例最高的 10 个属性如下：

| Attractive | 103,833 | 51.25% |
| Mouth_Slightly_Open | 97,942 | 48.34% |
| Smiling | 97,669 | 48.21% |
| Wearing_Lipstick | 95,715 | 47.24% |
| High_Cheekbones | 92,189 | 45.50% |
| Male | 84,434 | 41.68% |
| Heavy_Makeup | 78,390 | 38.69% |
| Wavy_Hair | 64,744 | 31.96% |

正样本比例最低的 10 个属性如下：

| 属性 | 正样本数量 | 正样本比例 |
| --- | ---: | ---: |
| Goatee | 12,716 | 6.28% |
| Chubby | 11,663 | 5.76% |
| Sideburns | 11,449 | 5.65% |
| Blurry | 10,312 | 5.09% |
| Wearing_Hat | 9,818 | 4.85% |
| Double_Chin | 9,459 | 4.67% |
| Pale_Skin | 8,701 | 4.29% |

属性类别并不均衡。例如 `No_Beard` 和 `Young` 的正样本比例超过 75%，而 `Bald`、`Mustache` 等属性低于 5%。训练属性分类模型时，仅使用准确率可能掩盖少数类别效果，因此应同时关注 precision、recall、F1-score 或 balanced accuracy，并考虑使用类别权重。

### 4.5 人脸关键点

关键点文件为每张图片提供以下 5 个关键点：

1. 左眼中心；
2. 右眼中心；
3. 鼻尖；
4. 左嘴角；
5. 右嘴角。

每个关键点由横坐标和纵坐标表示，因此关键点文件共有 `image_id` 加 10 个坐标列，共 11 列。全部 202,599 张图片均具有关键点标注，可用于人脸对齐、姿态分析和关键点定位实验。

## 5. 数据集对比与结论

LFW 的规模较小，身份分布高度不均衡，但图像包含丰富的非受控场景变化，并提供标准的同人/异人图片对，因此适合人脸验证和预训练模型评估。后续任务中可以直接使用预训练人脸识别模型在 LFW 图片对上计算余弦相似度，并根据阈值计算验证准确率。

CelebA 的图片数量和身份数量更大，每个身份通常包含多张图片，并提供属性、边界框、关键点和无身份重叠的数据划分。它适合用于人脸属性分类、人脸识别训练和关键点定位。但属性分布存在明显不均衡，实验设计和评价指标需要考虑少数类别表现。

综合来看，两个数据集可以形成互补：使用 CelebA 进行模型训练或属性、关键点实验，使用 LFW 完成人脸验证测试。
