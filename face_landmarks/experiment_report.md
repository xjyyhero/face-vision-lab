# 300W 人脸关键点与对齐实验报告

## 1. 实验目标

使用 MMPose 的 HRNetV2-W18 在 300W 数据集上进行 68 点人脸关键点定位，计算 NME，并依据关键点完成仿射人脸对齐。

## 2. 实验设置

| 项目 | 配置 |
|---|---|
| 数据集 | 300W |
| 关键点数量 | 68 |
| 模型 | HRNetV2-W18 |
| 输入尺寸 | 256 × 256 |
| 初始化 | MMPose 官方 300W 权重 |
| 微调轮数 | 1 epoch |
| Batch size | 16 |
| 学习率 | 0.0001 |

受可用 GPU 计算资源和实验时间限制，本实验采用官方权重进行低学习率单轮微调，重点验证数据加载、模型训练、NME 评估、关键点可视化和人脸对齐的完整流程。当前结果属于基线性能，不代表长时间训练后的最佳结果。

## 3. NME 结果

NME 越低表示预测关键点与真实关键点之间的归一化距离越小。

| 数据划分 | 微调前 NME | 微调后 NME |
|---|---:|---:|
| Full | 0.034505 | 0.034686 |
| Common | 未单独评估 | 0.029434 |
| Challenge | 未单独评估 | 0.056236 |

单轮微调后 Full NME 从 0.034505 变为 0.034686，差异很小，表明完整训练和评估流程已验证成功，但 1 epoch 不足以带来明显的性能提升。Common 子集表现最好，Challenge NME 明显更高，说明困难姿态和复杂成像条件仍是主要挑战。

## 4. 关键点结果分析

- 正面、无遮挡人脸：68 个预测点与真值整体高度重合，眼部、鼻部和嘴部定位较稳定。
- 大姿态或夸张表情：Challenge NME 为 0.056236，显著高于 Common 的 0.029434，说明困难样本上的定位稳定性较低。
- 遮挡与模糊人脸：局部特征不清晰时，模型更依赖整体脸形推断，预测偏差容易增大。
- 主要误差区域：脸部轮廓边缘、近闭眼眼睑边界及表情变化较大的嘴角。

## 5. 人脸对齐

使用左右眼中心、鼻尖和左右嘴角五个稳定点估计相似仿射变换，将人脸对齐到 256 × 256 标准模板。Notebook 结果显示，对齐后双眼、鼻尖和嘴角均落在预定的标准位置，人脸尺度和旋转得到了归一化。

## 6. 结论

本实验完成了 HRNetV2-W18 在 300W 数据集上的单轮微调、Full/Common/Challenge NME 评估、68 点可视化和五点人脸对齐。模型在 Common 子集上表现稳定，在大姿态、夸张表情、遮挡和模糊等困难条件下误差增大。受计算资源限制，本实验只微调 1 epoch，结果主要用于验证完整工程流程，不代表充分收敛后的最佳性能。
